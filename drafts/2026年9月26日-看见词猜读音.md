发音系列最后一篇，方向反过来。

前三篇解决的是「音怎么发、怎么变、轻重怎么摆」，这篇解决阅读时的问题：**碰到一个没见过的词，能不能看着拼写把读音猜个八九不离十？** 英语不是完全规则的拼读语言，但也绝不是毫无规律，下面八组是命中率最高的拼读规则，外加一份英美差异附录。

## 一、c 和 g 有软硬两读

同一个字母，后面跟什么字母决定它的读音：

| 字母 | 遇 e / i / y | 遇 a / o / u 或辅音 |
|---|---|---|
| c | /s/ 软音：city、cent、cycle、face、ice | /k/ 硬音：cat、cold、cup、class |
| g | 多为 /dʒ/：gentle、giant、gym、page、orange | /g/：game、go、gum、grass |

g 的软读有一批高频例外，必须单独记：get、give、girl、begin、gift、giddy、gilt 里 g 都读硬音 /g/。

## 二、ch 有三种读法

| 读音 | 例子 |
|---|---|
| /tʃ/（最常见） | chair、child、teacher、much、China |
| /k/（希腊来源的词） | school、chemist、choir、stomach、character、headache、mechanic |
| /ʃ/（法语来源的词） | machine、chef、champagne、Chicago |

## 三、-ough：一个拼写，七种读音

这是英语拼读里最出名的「不讲理」组合，七个高频词刚好把七种读法凑齐：

| 词 | 读音 |
|---|---|
| though | /ðəʊ/ |
| through | /θruː/ |
| tough | /tʌf/ |
| cough | /kɒf/ |
| bough | /baʊ/ |
| thorough | /ˈθʌrə/ |
| bought | /bɔːt/ |

同族词可以打包记：enough、rough 跟 tough；brought、thought 跟 bought；although 跟 though。规则推不出来，但就这十几个词，见到一个划拉一个。

## 四、-tion / -sion / -ssion / -cian

| 后缀 | 读音 | 例子 |
|---|---|---|
| -tion | /ʃən/ | nation、action、education |
| -ssion | /ʃən/ | mission、passion、discussion |
| -cian | /ʃən/ | musician、magician、physician |
| -sion（前面是元音字母） | /ʒən/ | decision、vision、occasion、television |
| -sion（前面是辅音字母） | /ʃən/ | tension、dimension |

## 五、ex 的三种读音

| 读音 | 条件 | 例子 |
|---|---|---|
| /ɪɡz/ | 后面接元音，且重音在后面 | exam、exist、example、exact、exhaust |
| /ɪks/ | 后面接辅音 | excuse、expect、explain、experience、express |
| /eks/ | 重音在开头 | expert、extra、excellent、exercise、exit |

## 六、th：实词多清，功能词多浊

两个读音 /θ/（清音，不振动）和 /ð/（浊音，振动），分工大体看词性：

| 读音 | 常见词 |
|---|---|
| /ð/ 浊：功能词几乎全是 | the、this、that、these、those、they、them、their、there、then、than、though、with |
| /θ/ 清：实词多是 | think、three、bath、mouth、month、author、method、nothing、both、thin |

注意例外：smooth 看着是实词，读 /smuːð/，是浊音。

## 七、同音异形：读音一样，拼写和意思不同

homophone 是听力和拼写双重坑，高频的几对：

| 同音组 |
|---|
| there / their / they're |
| to / too / two |
| know / no |
| see / sea |
| son / sun |
| hear / here |
| our / hour |
| week / weak |
| buy / by / bye |
| weather / whether |
| right / write |
| flower / flour |

## 八、同形异音：拼写一样，读音和意思都不同

heteronym 是反过来的坑，读错音就是另一个意思：

| 词 | 读法一 | 读法二 |
|---|---|---|
| read | /riːd/ 读（现在） | /red/ 读（过去） |
| lead | /liːd/ 带领 | /led/ 铅 |
| tear | /tɪə/ 眼泪 | /teə/ 撕 |
| bow | /baʊ/ 鞠躬 | /bəʊ/ 弓、蝴蝶结 |
| wind | /wɪnd/ 风 | /waɪnd/ 缠绕 |
| live | /lɪv/ 动词，居住 | /laɪv/ 形容词，现场的 |
| close | /kləʊz/ 动词，关闭 | /kləʊs/ 形容词，近的 |
| minute | /ˈmɪnɪt/ 分钟 | /maɪˈnjuːt/ 微小的 |
| use | /juːz/ 动词 | /juːs/ 名词 |
| desert | 见第三篇名前动后 | 同一批词也属于此类 |

## 九、附：哑字母的成规律组合

上一篇说哑字母要逐个记，其实常见组合就这几组：

| 组合 | 规律 | 例子 |
|---|---|---|
| kn- 开头 | k 不发音 | know、knee、knife、knight、knock |
| wr- 开头 | w 不发音 | write、wrong、wrist、wrap、wrote |
| -mb 结尾 | b 不发音 | comb、bomb、thumb、climb、lamb |
| -bt / -pt 中 | b、p 不发音 | debt、doubt、receipt |
| -lk 中 | l 常不发音 | walk、talk、folk、yolk |
| h 开头部分词 | h 不发音 | hour、honest、honor |

零散的还有 island 的 s、Christmas 的 t、listen/fasten/soften 的 t（often 的 t 可读可不读），没有组合规律，碰到再记。

## 附录一：高频「偷懒词」的标准读音

这些词拼写里的字母比读音多，逐个核对过：

| 词 | 读音要点 |
|---|---|
| Wednesday | /ˈwenzdeɪ/，第一个 d 不发音 |
| February | /ˈfebruəri/，第一个 r 常丢（两读都有人用） |
| vegetable | /ˈvedʒtəbl/，三个音节不是四个 |
| comfortable | /ˈkʌmftəbl/，三个音节 |
| restaurant | /ˈrestrɒnt/，两到三个音节 |
| family | /ˈfæməli/，两个音节常读成 |
| chocolate | /ˈtʃɒklət/ |
| library | /ˈlaɪbrəri/，别读成「li-ba-ry」 |
| business | /ˈbɪznəs/ |
| clothes | /kləʊðz/，一个音节 |
| interesting | /ˈɪntrəstɪŋ/，三个音节 |

## 附录二：英美读音差异高频词

| 词 | 英式 | 美式 |
|---|---|---|
| schedule | /ˈʃedjuːl/ | /ˈskedʒuːl/ |
| either | /ˈaɪðə/ | /ˈiːðər/ |
| dance / class / bath | /ɑː/ | /æ/ |
| advertisement | /ədˈvɜːtɪsmənt/ | /ˌædvərˈtaɪzmənt/ |
| leisure | /ˈleʒə/ | /ˈliːʒər/ |
| clerk | /klɑːk/ | /klɜːrk/ |

顺带一个 wh- 规律：what、when、where、why、whether 读 /w/ 开头；who、whom、whose、whole 读 /h/ 开头。

## 写在最后

四篇到这儿收尾。回头看这条线：先分清音素和音标，再接受声音会「变」，然后把重音语调立起来，最后反过来掌握拼读规律。**前面是嘴巴和耳朵的功夫，这一篇是眼睛的功夫。**

给孩子用的时候，这些规则别一次铺开，跟分级读物的进度走：读到 city 时点一句软 c，碰到 Wednesday 时读一遍标准音，一个学期攒下来，孩子见到生词就敢自己往下拼，这就是拼读规律真正的用处。
