usql 是一个用 Go 编写的**通用数据库命令行客户端**（GitHub: [xo/usql](https://github.com/xo/usql)），单二进制、无依赖，用一个工具、一套 psql 风格命令连接几乎所有主流数据库：MySQL、PostgreSQL、SQL Server、Oracle、SQLite、Doris（MySQL 协议）、ClickHouse、DuckDB 等。

**为什么值得用**：

- 不用为每种数据库装一个客户端（mysql-cli / psql / sqlcmd / sqlplus 全免）
- 反斜杠元命令全通用：`\dt` 列表、`\d 表名` 看结构、`\c 库名` 切库
- 输出格式对脚本和 AI agent 友好：一行参数切表格 / JSON / CSV
- 命名连接把 DSN（含密码）收进配置文件，日常只敲 `usql <名字>`

## 一、安装

### Windows（推荐：下载二进制）

1. 到 [GitHub Releases](https://github.com/xo/usql/releases) 下载 `usql-*-windows-amd64.zip`
2. 解压出 `usql.exe`，放到任意已入 PATH 的目录（如 `C:\Users\<你>\bin\`）
3. 验证：

```bash
usql --version
# usql 0.21.6
```

其他方式：`scoop install usql`，或有 Go 环境时 `go install github.com/xo/usql@latest`。

### macOS / Linux

```bash
brew install xo/usql/usql
```

Linux 也可以直接从 Releases 下载对应架构的 tar 包解压。

## 二、两种连接方式

### 1. DSN 直连（一次性查询）

```bash
usql mysql://user:pass@host:3306/dbname
usql postgres://user:pass@host:5432/dbname
usql sqlserver://user:pass@host:1433/dbname
usql oracle://user:pass@host:1521/service
usql sqlite3://D:/path/to/file.db      # sqlite 用文件路径形式
```

### 2. 命名连接（日常推荐）

配置文件位置：Windows 在 `%APPDATA%\usql\config.yaml`，macOS/Linux 在 `~/.config/usql/config.yaml`（yaml/json/toml 均可，viper 解析）：

```yaml
connections:
  doris:
    protocol: mysql
    hostname: <host>
    port: <port>
    username: <user>
    password: <password>
    database: <db>
```

之后直接：

```bash
usql doris        # 进交互式 REPL
usql doris -c "SELECT 1"   # 单条命令
```

> ⚠️ **安全提醒**：该文件含明文密码，不要提交进 git、不要贴进文档/截图/聊天记录。团队协作时只分享"配置结构"，各自填自己的凭据。

## 三、最常用形态（实测示例）

以下示例中的 `doris` 是一个指向 Doris 数仓（MySQL 协议）的命名连接，换成你的连接名即可。

### 表格输出（默认，给人看）

```bash
usql doris -c "SELECT version() AS doris_version, now() AS server_time"
```

```
 doris_version |        server_time        
---------------+---------------------------
 5.7.99        | 2026-10-15T17:48:39+08:00 
(1 row)
```

### JSON 输出（给脚本 / AI agent 消费，首选）

```bash
usql doris -q -J -c "SELECT 1 AS id, '示例' AS note UNION ALL SELECT 2, 'JSON输出'"
```

```json
[{"id":1,"note":"示例"},{"id":2,"note":"JSON输出"}]
```

### CSV 输出（给 Excel / 落盘）

```bash
usql doris -q -C -c "SELECT 1 AS id, '示例' AS note UNION ALL SELECT 2, 'CSV输出'"
```

```csv
id,note
1,示例
2,CSV输出
```

`-q`（quiet）去掉连接提示等杂音，只留查询结果，管道必备。

### 跑 SQL 文件 / 结果落盘

```bash
usql doris -f query.sql              # 执行文件里的所有语句
usql doris -q -C -f query.sql -o out.csv   # 结果直接写 CSV 文件
```

## 四、交互式 REPL

不加 `-c` 即进入 REPL，元命令以反斜杠开头：

```bash
usql doris
```

```
doris=> \dt                    -- 列出当前库所有表
doris=> \dt ads.*              -- 按模式过滤
doris=> \d ads_fin_expense_analysis   -- 查看表结构（列/类型/注释）
doris=> \c dw                  -- 切换数据库
doris=> \?                     -- 查看全部元命令
doris=> \q                     -- 退出
```

`\dt` 实测输出（节选）：

```
                                  List of relations
      Schema       |                        Name                        |    Type    
-------------------+----------------------------------------------------+------------
 __internal_schema | audit_log                                          | BASE TABLE 
 __internal_schema | column_statistics                                  | BASE TABLE 
 ads               | ads_...                                            | BASE TABLE 
 ...
```

## 五、命令行参数速查（`usql --help`）

| 参数 | 作用 |
|---|---|
| `-c, --command` | 执行单条命令（SQL 或元命令）后退出 |
| `-f, --file` | 执行 SQL 文件后退出 |
| `-o, --out` | 输出写入文件 |
| `-q, --quiet` | 安静模式，只输出查询结果 |
| `-J, --json` | JSON 输出 |
| `-C, --csv` | CSV 输出 |
| `-G, --vertical` | 纵向输出（宽表好用） |
| `-x, --expanded` | 展开表格输出 |
| `-t, --tuples-only` | 只打印数据行（无表头） |
| `-A, --no-align` | 非对齐输出（配合 `-F` 自定义分隔符） |
| `-1, --single-transaction` | 文件内语句包成一个事务执行 |
| `-w, --no-password` | 绝不提示输入密码（脚本防卡死） |
| `-X, --no-init` | 不执行初始化脚本 |
| `--config` | 指定配置文件路径 |
| `-V, --version` | 输出版本 |

## 六、使用建议

1. **人看用表格，机器用 JSON/CSV**：交互排查直接 `-c` 表格；接管道、喂 agent 一律 `-q -J`
2. **命名连接收口凭据**：DSN 只在配置里写一次，命令行历史里不留密码
3. **大查询先写文件**：长 SQL 放 `.sql` 文件用 `-f` 跑，避免终端转义问题
4. **REPL 里 `\?` 是宝藏**：`\copy`、`\watch`、变量 `\set` 等高级用法都在里面
