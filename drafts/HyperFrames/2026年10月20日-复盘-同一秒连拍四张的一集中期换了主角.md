这一集教的是「烤片之前，把每一帧看清楚」：工程里三个元素同一秒开演，preview 里又顺又稳，让机器对同一秒钟连拍四张 snapshot，蓝方块纹丝不动，绿点钉死在同一相位，红方块却四张图四个位置。片子拍完，制作过程自己贡献了一个更曲折的剧本——开拍前探针押错了事故主角，录屏彩排被像素证据当庭翻案，稿子、配音、封面全部跟着重来了一遍。

这篇速读记录 hf-07《把每一帧看清楚》从探针到发布的全周期：中期翻案花了多大代价；grade-compare 怎么白烤一遍还不报错；559 秒的片子为什么烤了 41 分钟；以及 F2 二轮复查这集升级的词级正音抽检。细账在同组四篇深读里。

## 一、9 分 21 秒、20 幕、273 句

终片 561.233 秒（封面头 2.000 秒＋正片 559.233 秒），55,869,542 字节，20 个分镜幕，273 句逐字字幕，口播 22 段、2276 个汉字。check **0 error**，22 条 nested_structure warning 是五片以来的基线接受项，Layout、Motion、Runtime 三个阶段 0 issue，文字对比度 **68/68 全过 WCAG AA**。字幕时间偏移照例先测 onset 再定，这集 measure_offset 量出中位数 +315 毫秒，取 **time_offset 0.31**，系列七片排成 0.28/0.37/0.29/0.30/0.29/0.31/0.31。

发布信息：**BV1zkJf67EVC**，2026-10-20 中午 12:38 投出，tid122 野生技术协会，挂进合集「HyperFrames 入门教程」（9327492）小节「正片」，自动排在第 7 位，01 到 07 天然有序。发布前最后一道工序是叶扬本人的耳朵——50 段、3.1 分钟的正音抽检合集听完，结论两个字：「没问题」。

## 二、同一秒，四张照片

这集的核心证据是一张接触表。工程里三个元素：蓝方块交给 GSAP 从左滑到右；绿点是写网页最常见的 CSS keyframes 喘气动画；红方块也是从左滑到右，可它不归任何动画库管，是脚本里一个 setInterval，闭包揣着自己的计数器，一下一下挪位置。命令是 snapshot，时点写四个一模一样的第二秒：

![同一秒钟连拍四张的接触表：蓝方块四帧同位，绿点四帧同相位，红方块四帧四个位置；接触表命令行与 t=2.00s 时标清晰](https://raw.githubusercontent.com/yeyangchen2009/draft-review/main/assets/hf07-review/hf07r01-contact4.jpg)

蓝和绿纹丝不动，红方块四张图四个位置。道理是两种动画过两种时间：GSAP 和 CSS 动画都登记在时间轴上（CSS 由浏览器内部的 WAAPI 统一接管），seek 到第几秒就停在第几秒的相位；闭包里自己掐表的脚本只认真实过了几秒，seek 管不着。叶扬还做了一个边界实验补刀：把红方块的表调慢到一分钟一圈，进度条停在第十秒，蓝块八秒走完全程早在终点等着，红块才走六分之一，还贴在起点附近。

值得专门说一句的是绿点——CSS 在这集里是被平反的好人。loading 转圈、按钮 hover、弹窗淡入，跟着墙钟走对网页天经地义；错的是把网页习惯搬进「求每一帧的解」的烤片炉。

## 三、中期翻案：探针押错，像素翻案

这集最大的一笔额外成本发生在 10-19 晚上。前制探针阶段，叶扬把「seek 定不住」的教学事故押在了 CSS keyframes 上——直觉来自 hf-04 计数器事故的延续假设。三工程布景冻结、12 个 case 的像素彩排跑完，证据反过来了：绿点在四帧里钉死同一相位，CSS 经过 WAAPI 被 seek 完整接管；真正四帧四位置的，是那个不注册 window.__timelines、不读 Date.now、不用 requestAnimationFrame、关起门在闭包里自己记数的 setInterval。

体检报告也给黑户做了三连证明：不加参数的 keyframes 报告里明明白白只有三个 items，红块压根没户口；用 `--shot '#bad'` 直接点它，机器硬报错「这个选择器下面没有动画在动」，还善意列出离得最近的三个登记户；而这段脚本只要敢读系统时间或者用 rAF，check 当场就拦——它偏不，check 于是一路绿灯。

翻案的代价是真金白银的 2.5 小时：src 从 21 段扩到 22 段，2276 个汉字里三元素布景、墙钟段整段重写，新增慢表边界段，CSS 叙事整个反过来；11 个段落在蝉镜试听通道重新合成（0 蝉豆），母带从 440.17 秒变成 559.22 秒；转录、273 句 cues、time_offset 全部重跑；连早已截好的封面都得追改。深读之一讲完整过程。

## 四、grade-compare：白烤一遍，警告倒是发了

另一档事故发生在调色工具上。grade-compare 拿同一帧套几种调色摆一块儿选片，叶扬图省事，按写网页的习惯在 grades.json 里写了一串 CSS filter——配置格式根本不认这个，未知 preset 被归成 ADJUST_ZERO，三格画面一模一样，等于白烤一遍。机器没有瞒报：终端明明白白打了两条黄警告，「这一档 inactive/no-op，渲染出来不会调色」。问题是这种「活照干、警告照发」的静默失败，彩排闸原本只查「图出了没有」，查不出「三格是不是一样」。

修法两层：配置改回工具自己的 adjust 对象（暖色档调 temperature/saturation/exposure，高亮档调 exposure/contrast）；彩排闸补到三条——命令退出码、成图里不得出现 inactive/no-op 字样、2×2 四个格位逐格算像素差异（MAD 大于 6 且显著像素超过 25%；真机暖色 11.8/94%，高亮 13.7/94%）。另外学到：active grading 在这台机器的无头硬件渲染模式下必挂导航超时，退路是 software GPU 加 30 秒超时，单次彩排 33.8 秒，等待常量从 20 秒放宽到 40 秒。深读之二连同代录首跑撞出的两个脚本 bug 一起讲。

## 五、41 分钟烤 16777 帧，worker 只有一个

render 一次过，账如下：产物 55,655,792 字节（53.1MiB），559.233 秒，1920×1080，30fps CFR，整 **16777 帧**。分阶段：video_extract 35.7 秒（11 段屏录源抽出 2090 帧，每段上限 300，VFR 预检 0 报警），audio 48.2 秒，capture 本体 **2349.4 秒（39 分 9.4 秒）**，总墙钟 **41 分 43.3 秒**。

这集 worker 降到 **1**：页面里含视频元素的工程在这台无独显机器上统一单 worker 截图，走 drawelement capture 快路径（全片没有 blur）、SDR、hardware gpu。跟上一集不做简单横比——hf-05 是五 worker 加 PNG 帧烤了 69 分钟，hf-06 是 jpg 帧 28.5 分钟，页面复杂度不同。这笔账再次把规矩压实：改一句文案就要 41 分钟起步，所有能左移的核对全部压到 render 之前。

进 render 之前还有一道帧率门禁，这是 hf-04 用崩掉的抽帧换来的：9 段 gdigrab 母带探针一算全是 VFR，平均帧率只有 10.7fps；精切统一 `-vf fps=30 -g 30` 重建 CFR，10 段 shorts 再探全是 30/1，门禁才放行。

## 六、F2：从整段 20 秒到词级 ±0.6 秒

成片之后的 F2 复查走三层。

客观层：whisper 复转 155 段通读，2535 行字级对齐，15 个 GAP 逐个归类——11 个是「儿、呢、的、时」的轻声轻读，属正常；真正交人耳的只剩 4 个点（「第二秒」三连、掐头去尾、八百/五百）。

人耳层这集升级了切窗工艺。hf-05 的做法是按整个语音段切，长段窗口达 20 秒，50 个点听下来很累；这集的 f2_pronounce.py 直接读 raw.json 里的**词级时间戳**，沿词定位命中点，前后只留 0.6 秒——43 个正音窗（33 条 needle 同串全收：双音 tiáo/diào 各读各音、累加 lěi、薛定谔 xuē、Anime 不等于 animate、setInterval 在 P2/P7 两处的念法、道别句「我们下期见」——whisper 把它听成了「佛门」，这种必听）加 8 个节拍窗、16 个段界窗（11 个新旧跨界点自动标好方向，专听电平与音色衔接），相邻不足 0.8 秒的自动合并，最终 **50 段、3.1 分钟**，配一份逐句索引。定位失败时回退整段切，不丢点。

视觉层：公共抽帧件 frames_at.py 对终片抽 14 个点出 sparse-keyframe 接触表，封面、三元素登记卡、慢表真机、grade 黄卡、render 预告全部在位；459 秒一格缩略图偏空，原分辨率补抽确认是「标签按逗号分段」黄卡的正常构图，虚惊一场。

## 七、这集新长出来的六条规矩

1. **教学事故要在真机布景上用像素断言验证到「seek 不可定」级。** 纸面归类会翻案，翻案的价码是 11 段重合成、母带 440.17→559.22 秒、cues 重对齐加封面返工。
2. **静默成功最危险。** CSS filter 串在 grade 配置里是未知 preset，ADJUST_ZERO 静默 no-op，只留一条黄警告；闸必须查「三格是否真的不一样」，不能只查「图出了没有」。
3. **彩排闸要覆盖 harvest 全路径。** 代录脚本首跑撞出 RGBA 解包和 harvest 调用两个 bug，12 次彩排全绿却没拦住——因为彩排只跑像素断言，不经过产物归位函数。
4. **双类规则拆源：定位归定位，视觉归视觉。** 同元素挂两条同特异性规则，源码在后的 left:0 能把卡片打回左上角；gsap.from 还有「容器只对子元素 from、空框先显形」的新变体。
5. **封面先行，翻案必追。** 封面在稿之前锁定立意是好流程，但主角翻案后必须回头核对封面事实，finalize 前的抽帧闸这集抓住了一处与成片直接矛盾的图例。
6. **F2 切窗用词级时间戳。** 客观证据负责把 273 句收窄成 50 段 3.1 分钟，「这样能不能发」由耳朵的主人一句话定。

下一集进入正片结尾留的钩子：照片都验干净了就该真烤了——无头浏览器怎样把网页一帧帧烤成 MP4，上万帧要烤多久，烤崩了怎么查。下一集，render。
