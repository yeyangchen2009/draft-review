哈喽大家好，我是叶扬。

上一集，台子搭好了。

可你打开浏览器看看，舞台中间那行字还是「Hello HyperFrames」——样板，不是你的东西。

这一集，把样板请下去，做头一个真正属于你自己的片段。

动手前先掰一个观念：在剪辑软件里，片段是鼠标按住、往时间轴上拖出来的；HyperFrames 里没有这回事——时间，是你拿键盘，一个数字一个数字写在 HTML 标签上的。

打开 index.html，找到中间那行 h1。

先盯住它身上的属性：class="clip"，data-start="0"，data-duration="10"。一个章，两个数字。

章，是 class 等于 clip。clip，片段。想让一个网页元素成为视频里的片段，就得盖这个章；没有它，渲染器扫过页面当没看见，字写得再大、颜色再艳，也进不了成片。

两个数字管生死：data-start 等于 0，从零秒上场；data-duration 等于 10，待十秒。什么时候进、什么时候走，全写在这儿。

旁边还跟着一个 data-track-index，先混个脸熟：它只给 Studio 的时间轴分轨道、排显示用，渲染成片的时候程序根本不读，别拿它当开关。

动手前还有件事。样板默认从网上的 CDN 加载 GSAP，真做项目，我习惯把库下载到本地，地址换成一个 gsap.min.js——断网也能渲染，版本钉死在本机，上游再怎么变，都带不跑你。

好，玩点真的：让标题第二秒再进来，第六秒就走。data-start 改成 2，data-duration 改成 4，2 加 4 正好 6。再把标签里的字换成自己的——「我的第一个片段」。

回到浏览器，刷新，点 Preview 中间那个 Play。

看见没有：开头两秒，舞台空荡荡；第二秒，标题进来；第六秒一到，干干净净，消失。没有鼠标拖动，就改了两个数字。

一个片段不过瘾，再加两个。

想在画面里自由摆位置，得先给定位一个锚——在 #root 上加一句 position: relative。然后把两张「脸」先画进样式里：一张卡片，琥珀色大字；一行副标题，灰色小字。都是普通 CSS。

先加卡片：data-start 等于 3，duration 等于 2。标题是 2 到 6，卡片 3 到 5，故意撞个满怀。

注意它写在哪儿：标题标签的后一行。浏览器有个几十年的老脾气——HTML 里谁写在后面，谁就盖在上面。我干脆把这句话直接写进了卡片里：「HTML 里后写的，盖在上面」。

想反过来呢？不用跟 z-index 较劲。Notepad++ 里，光标点上去，Alt+Up，整行提走。标签顺序一换，上下立刻翻转。调层叠最稳的办法，就是挪标签顺序。

再放副标题：data-start 等于 6，duration 等于 4。标题第六秒前脚走，它后脚来，两个片段在时间上排得整整齐齐，互不打架。

我还把这集的心得，直接写成了副标题里的字——「零行 JavaScript，先出片子」。

到这儿你发现没有：标题多大、什么颜色、谁盖着谁、几点进几点走，全是写网页的那身老手艺，从头到尾没写过一行脚本。可就是这么一个纯静态页面，它已经是一条有精确起止、随时能渲染的视频。

先学会摆，再学会动。

摆完别急着渲染，先让机器替你看一眼：npm run check。

忘盖章的、时间写出界的、把秒当帧、抬手填个 90 上去的——这些新手常栽的坑，它都替你盯着。

咱们这页，也跑一下。

红了。布局一项，content_overlap：第三秒到将近第五秒，卡片和标题撞在一起，两块文字重叠，可能没法读。

别急着辩解，看它下面这行 Fix——连怎么改都替你写好了：要么给每块文字各自的地盘；要么，故意的层叠，就盖个章声明一下，data-layout-allow-overlap。

这次重叠本来就是我设计的。那就按它说的，在卡片标签上加一个 data-layout-allow-overlap。

再跑一次。

绿了：Lint 零错误，运行时零错误，布局零问题，对比度四项全过 WCAG AA——Check passed。

看懂这个流程没有：check 不是拦路虎，是守门员。它不反对重叠，它反对的是「没打招呼」的重叠；你确认是故意的，就拿属性明明白白告诉它。

过了 check，preview 里再肉眼走一遍，几点出现、几点消失都对得上，这集就算齐活。

不过你也看出来了，现在的画面还「活」不起来：标题不会飞进来，字不会一个个点亮，卡片也不会翻。

是谁管这些？下一集，整个系列最核心的一集。

我们要讲清楚，为什么 GSAP 的时间轴必须先暂停住，还得到 window.__timelines 那张表上报个到——渲染器才有办法「跳到任意一秒，画面立刻就位」。

灵魂在 seek。hf-04，我们接着来。

我是叶扬，我们下期见。
